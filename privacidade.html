Política de Privacidade

GTA6 Dark Publicador · atualizada em 13 de novembro de 2026

Quem usa

O GTA6 Dark Publicador é uma ferramenta de uso pessoal. O único usuário é o dono do canal Arquivos de Vice City | GTA 6.

Quais dados usamos

Ao conectar uma conta do YouTube (Google), a ferramenta recebe um acesso (token) que permite enviar vídeos ao canal e ler o nome e a foto do canal. Esse acesso é guardado criptografado no servidor da própria ferramenta.

Para que usamos

Apenas para publicar, no canal do próprio dono, os vídeos que ele aprovou, nos horários que ele escolheu. Os dados não são vendidos, compartilhados com terceiros nem usados para publicidade.

Uso de dados das APIs do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. A ferramenta também usa os Serviços de API do YouTube; veja a Política de Privacidade do Google.

Como remover o acesso

O acesso pode ser removido a qualquer momento desconectando a conta na ferramenta ou em myaccount.google.com/permissions. Ao desconectar, o acesso guardado é apagado.
